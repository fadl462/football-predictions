# UX inspiration pass — Betway-style patterns, DZ Football Edge implementation

This project does not copy Betway branding or interface. It borrows useful interaction patterns observed on Betway's public sports experience and adapts them to a prediction product.

## Patterns adapted
- Persistent sport/competition navigation → Algeria-first league chip bar.
- Search for teams, matches and sports → quick search modal.
- Popular leagues and filters → Ligue 1, Ligue 2, Coupe and CAF filters.
- Live / upcoming segmentation → Live & À venir centre.
- Match-centre detail → live score, possession, shots and quick analysis preview.
- Many football market categories → prediction-market tabs for 1X2, Double Chance, BTTS and Goals.
- Favourite teams/leagues → local favourites interaction.
- Bet-slip-style persistent selection → "Mon Edge" prediction collection, intentionally not a wagering slip.
- Promotions/boost surfaces → original "Edge Boosts" editorial layer.
- Mobile-first navigation → compact sticky header and horizontal league navigation.
- Strong fixture discoverability → searchable match list with day and league filters.

## Product-specific improvements
- Transparent prediction history rather than promotional claims.
- Confidence and signal labels are presented as model outputs, not guarantees.
- VIP is positioned as premium data access rather than guaranteed winnings.
- Demo mode is clearly labelled until the server-side application is deployed.
